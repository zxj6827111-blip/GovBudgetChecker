# 文字层 PDF 规则完善与自检报告

日期：2026-10-08。当前分支：`codex/zcode-remediation`。本轮针对用户提供的可选择文字的真实决算 PDF，完善表格与说明的对应、规则勾稽和证据定位。

## 审校及修复结论

本轮开发修复和自检通过。20 份原件全部完成实际导入、解析、规则运行、入库及四格式导出；金额校正后的缓存重审也已通过。四份重点材料的原文复核与实际服务结果对照，原先确认的数字漏报均已检出，本轮追加发现的四项误报均已消除。

这批材料为 2025 年度上海市部门决算公开，共 678 页，全部有文字层。发布日期和来源链接未提供，不补造。原件字节和冻结的人工判断均保持不变。

当前系统能够分别提取 PDF 文字与表格，把跨页表格重建为逻辑表，并按规则进行表内、表间和表文比对。比较依赖同一单位、年度、资金口径、预算阶段及业务分项的操作数；无法确认的身份或空白金额如实标为待复核。

本结论覆盖本轮已执行的开发复验。正式独立盲测尚未完成，不能据此宣布整个产品验收通过或推断全产品准确率。本轮没有重新执行原始扫描件链路，文字层材料的结果不能替代扫描性能和 OCR 准确性结论。

## 具体完善内容

| 方面 | 本轮行为 |
| --- | --- |
| 表格身份 | 说明页、定义和正文候选不再被二次识别成核心表；真实表的代码、置信度和列映射保持优先。数据局第21页不再产生假总表。 |
| 三公完成率和占比 | 按业务分项绑定当前三公表中的预算、决算和合计。完成率使用该分项预算，结构占比使用三公决算合计；不串用其他分项或阶段。 |
| 表文金额 | 显式识别年初预算与支出决算，支持软换行及已确认物理页码造成的断词；收入分项按指标身份比较，使用 Decimal 和0.5万元容差。 |
| 表格勾稽 | 支出表纳入经营、上缴和附属单位补助等组成列；经济分类使用完整明细和当前事实，不再漏计断行科目后报假差额。未知或空白不制造零值。 |
| 功能分类与基金说明 | 一般公共预算说明不吸收基金章节；基金项目说明支持“用途—年初预算—支出决算”模板，只绑定明确的决算金额。 |
| 文字规则 | 定性“基本持平”不等同严格零增长；增加同条同比复算、政府采购总额与三项之和、仅重述结果的原因说明，以及编号跳号检查。 |
| 证据 | 每个计算操作数保留当前事实身份、原单元格、原物理页、坐标和原文；跨页引用分别保存。计算解释不冒充 PDF 原文。 |
| 完成状态 | 有声明却缺少分母、列或业务身份时返回未完成，保留已经确认的其他问题；不把跳过比较记为通过。 |

四份重点原件共确认10组问题，系统检出12处对应关系：9处数字错误、2处原因说明不足及1处编号问题。同一组同比问题对应三条独立原文，不以重复展示增加缺陷组数。

重点原件实际输出共30条：9条high、2条medium、1条low、16条info，以及2条跨表尾差manual_review。30条全部通过原文、来源身份、原物理页及坐标校验；实际 API 导出与直接规则复跑逐条一致。

四项追加误报的处理分别为：教育V33-108绑定预算/决算阶段；教育V33-226使用精确小数与金额容差；教育V33-227限定资金章节；信访V33-243遇到未知明细编码时记录未完成，消除漏计明细产生的291.35万元假差额。另数据局上一轮的过强语义告警和假总表已经消除。

这不是全产品精确率或召回率。冻结后保留的所有原文判断、对照结果和分歧裁决均可复查。

## 待人工复核

20份材料的诊断义务为815/860已完成；未完成45项中，20项为未请求的可选AI检查，25项为确定性关系缺少可靠操作数或说明匹配。这个数字表示可执行范围，不能作为准确率。

具体包括表内空白金额、四份经济分类表的科目编码断行/身份不明、编码与名称冲突、基金项目名称不完全对应以及少数未披露的三公分项。每个具体子关系的原因和已有操作数留在执行回执中，已经确认的问题不因其他关系未完成而丢失。

生态第36页“接待总额45.57万元、国内44.72万元（含外宾0.85万元）”存在口径疑点。因为其他国外接待范围未确认，复核后保守列为manual_review，不判确定金额错误；冻结的原判断没有回写。信访两条跨表0.01万元尾差保留待复核，不计确定错误。

上一年度原公开文件、原始及调整预算、底层合同和完整官方科目库未包含在本次输入中。由本文件金额反推的上年基数会标为推导值，不冒充已读取的上年材料。
