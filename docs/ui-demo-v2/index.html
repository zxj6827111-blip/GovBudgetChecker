v2 设计重点

把地区范围、预算审校、决算审校放进同一个清晰工作流

本轮不改正式业务页面，也不做统一门户首页。DEMO 仅用于确认信息架构、视觉语言和工作人员的主要操作路径。

1
先选地区行政区划决定可见部门、单位和公开站点。
2
再选组织部门、单位决定任务归属和权限边界。
3
区分预算蓝色工作线，对应预算规则包和预算表。
4
区分决算青绿色工作线，对应决算规则包和决算表。
01 登录页
