# 主管端使用与验收说明

入口：`/supervision`。admin 和工作人员可从左侧“主管驾驶舱”固定入口进入，工作台右上角“查看主管端”也保留；旧版后台的管理员顶栏同样提供“主管驾驶舱”。沿用当前登录账号，无需另外开账号。主管只读账号登录后直接进入主管端。

## 四个页面

| 页面 | 主要内容 |
| --- | --- |
| 主管总览 | 报送进度、未交齐部门、人工确认问题、多轮整改仍有问题、问题分类、部门 Top 5 / Top 10 |
| 报送台账 | 部门汇总与材料明细切换；部门/单位检索、状态筛选，20 / 50 条分页；部门可下钻到所属材料 |
| 问题分析 | 当前版本的人工确认问题，按部门、类别、严重程度筛选，跳转对应材料 |
| 整改追踪 | 正式登记的整改材料及历史不完整的材料；材料详情展示复核记录、登记轮次、已修复/仍存在/新增问题 |

范围、财政年度、预算/决算在四个页面间保留。导出 CSV 包含当前范围和筛选下全部匹配记录，不限当前页。

首次通过裸入口进入时，系统选择当前授权范围内最新存在材料台账的年度和文种；应交但尚未上传的台账也计入，避免隐藏最新年度的缺交情况。URL 已明确指定年度或文种时保留该选择；仅补齐未指定的筛选项。当前年度/文种没有台账时，页面明确提示，并提供本范围内已有年度/文种的切换按钮。

## 给客户开账号

1. 管理员进入系统管理的用户管理。
2. 新增普通用户，勾选“主管只读账号”，选择授权区、部门或单位（包含其下级组织）。
3. 一个账号可以配置多个授权范围；不允许空范围的主管账号，也不允许同时为管理员和主管只读。
4. 客户只能读取授权范围。上传、重分析、问题表态、完成复核、清单确认、整改登记等写接口会在服务端拒绝。
5. 对既有工作人员账号切换角色后，旧会话失效，需重新登录。

客户账号仍使用现有登录和首次改密流程，本次没有创建真实客户账号或改动现有密码。

## 确认应交清单

未上传数量必须有完整的应交材料分母。仅统计已经上传过的单位，会漏掉从未上传的单位。

工作人员先在既有材料台账导入并核对完整的本年度名单，再进入主管端的“报送台账”，选定组织、年度、预算/决算，在底部填写依据并确认清单。确认面向该完整范围，不受搜索和分页影响。空清单、身份映射待确认、口径冲突或未解决适用性不能确认。

未确认时，应交总量、尚缺数量、完全未交/部分未交部门和报送比例显示“—”。已知上传数量仍显示。确认后，不适用材料不计入应交分母。增加/删除材料导致清单成员变化时，分母重新标为未知，需再次核对确认。清单按所选组织、年度和文种独立确认，不向下级选择范围自动继承。

## 正式整改如何形成一轮

1. 原版本完成人工复核并保留确认问题反馈。
2. 在原反馈之后上传不同内容的新文件，沿用同一材料槽位。
3. 工作人员在主管端材料详情填写依据，登记新版本为一次整改提交。原文件重新分析和普通文件版本数不增加整改轮次。
4. 新版本完成既有工作人员人工复核。
5. 在材料详情将每个旧问题明确标为“经原文核验已修复”，或关联到本轮仍存在的确认问题，并填写原文依据。未关联的本轮确认问题记为新增。

问题数量下降和问题 ID 消失均不会自动判定修复。复验结果绑定具体文件版本、分析代际和复核会话；已保存结果保留为审计记录，不覆盖。复核重开或重新分析后，旧结论作为历史展示。

新完成的复核会保存确认问题身份快照。历史记录只有计数而没有问题身份时，展示历史不完整，不能自动补造旧问题或修复数。

## 统计口径

- 当前统计严格关联材料槽位当前文件和当前分析；旧版本确认问题不会累计进入当前总量。
- 人工确认问题、待复核线索、未完成人工补核分别统计。缺少检查覆盖记录显示未知，不能用零替代。
- 问题材料占比以已完成人工复核材料为分母，并显示样本数；未复核材料不能作无问题样本。
- 多轮整改以同一材料登记两轮及以上且当前仍有人工确认问题统计，不按部门内各单位的上传次数求和。
- 问题分类使用真实标题关键词，无法匹配保留“其他问题”。历史计数没有明细时保留“历史确认问题未细分”。严重程度缺失不猜等级。
- 逾期未上传只根据已记录、带时区的截止时间和适用性判断；截止时间未知不推断逾期。

## 实现与运行

后端新增 `/api/supervision` 查询、CSV、清单确认和整改接口；前端代理使用既有会话。数据库迁移 `2026-10-13_0030_supervision` 新增两张表 `supervision_baselines`、`supervision_rounds`。沿用既有迁移启动流程，不需要新依赖。

统计按授权范围批量读取槽位、运行、复核和整改记录。当前查询仍在服务层计算分类和排名；几百个单位有隔离 PostgreSQL 用例，未对上万份长报告或生产并发做容量承诺。

最小验收：以两个不同区/部门的主管账号分别登录，确认只看到各自数据；切换年度和文种；从排名下钻；确认完整应交清单后检查尚缺数量；完成一份材料的两轮整改并逐条复验；核对导出全量与分页总数。真实账号开设、应交清单确认、历史整改补录须由工作人员按实际业务操作。
