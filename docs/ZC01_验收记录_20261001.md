## 1. 修改摘要

### 统一契约类型（任务包 §二.1 → `src/schemas/parse_artifact.py` 新建）

- `ParsedCell` / `ParsedTable`：权威定义收敛到 schemas，`src/services/pdf_parser.py`
  按原导入路径兼容导出，既有消费方不变。
- `ParsedCell` 新增 `normalized_value_wan`（万元 Decimal，序列化为十进制字符串）
  与 `presence`（空白/零/破折号/无此项/未识别分别处理）；`ParsedTable` 新增
  `fragment_uid`（物理片段身份）。
- `LogicalTableInstance`：跨页逻辑表实例，`instance_uid` 为唯一身份，主体/年度/
  资金范围是身份的一部分；`identity_conflict` 标记续表身份冲突（ZC-02 消费）。
- `EvidenceRef`：文件哈希 + 物理页 + 来源对象 + 原文 + bbox + 来源方式 +
  验证状态（默认 `unverified`）+ 定位等级。
- `FiscalFact`：主体/合并范围/年度/期间/资金范围/预算阶段/指标/科目身份 +
  原始值 + 单位 + 显示精度 + 万元归一值（Decimal）+ 证据引用 + 识别状态；
  `identity_key()` 明确"金额不参与身份"。
- `ParseArtifact`：文档哈希、解析器/配置/OCR 指纹、逐页状态、表片段、逻辑
  实例、坐标空间；`to_dict/from_dict` 全程 Decimal 字符串化。
- `CheckReceipt`：六态子检查回执（ZC-03 消费），非法状态构造即拒绝。

### 单位归一（SYS-15）

- `src/engine/amount_math.py` 新增 `normalize_amount_to_wan(value, unit)`：
  元=0.0001 / 千元=0.1 / 万元=1 / 百万元=100 / 亿元=10000；
  无单位信息返回 None，不猜口径。
- `ParsedCell.__post_init__` 解析时自动归一：`numeric_value`（页面字面值）与
  `normalized_value_wan`（万元）并存。

### 表实例身份（SYS-16）

- 新增迁移 `2026-10-01_0022_unified_parse_storage`：`parse_runs`（缓存键 =
  文档版本 + 原件哈希 + 解析器指纹 + 配置指纹 + OCR 指纹）、
  `parse_table_instances`（UNIQUE(parse_run_id, instance_uid)——表种不再唯一）、
  `parse_table_cells`（UNIQUE(parse_run_id, instance_uid, row_idx, col_idx)）、
  `parse_facts`（UNIQUE(parse_run_id, fact_uid)）、`parse_evidence`
  （verification_status 默认 'unverified'）。
- 旧表（fiscal_table_cells / fiscal_table_instances / fact_fiscal_line_items）
  保留历史读取与既有消费方；`fact_fiscal_line_items` 增加
  `normalized_amount` / `instance_uid` 兼容列（历史行不回填，迁移不伪造）。

### 一次解析、全程消费（SYS-01）

- 子进程解析 worker（`pdf_parse_process._pdf_parse_worker`）在同一次
  `pdfplumber.open` 内同时产出 page_texts/page_tables 与统一解析对象
  （`parse_artifact`），IPC 随 payload 传递；产物构建失败只降级为 None
  （入库回退独立解析），不影响文本/表格抽取本身。
- 线程池路径（`PDF_PARSE_ISOLATION_ENABLED=false`）同样一次打开双产出。
- `api/main.py` 重建 `ParseArtifact` 并传入 `run_structured_ingest`。
- `run_structured_ingest` 重构：先查解析缓存（命中→从统一存储重建，不重开
  PDF）；传入 artifact 直接消费；都没有才真正解析一次。旧表写入改由
  `PDFParser.persist_artifact_to_legacy_tables` 从 artifact 适配产出——
  **结构化入库不再重开 PDF 第二遍**。
- `FiscalFactMaterializer.build_fiscal_facts_for_table`：从 artifact 纯函数式
  物化 FiscalFact（身份+原值+归一值+证据），资金范围按表种语义映射
  （`infer_fund_scope`，无据不猜）。
- `src/services/parse_artifact_store.py`：统一存储的幂等落库与重建。

### 分析结果版本化

- `api/runtime.py` 新增 `write_analysis_revision_snapshot`：终态结果写入
  `uploads/<job>/analysis_versions/rev-*/status.json`，`current.json` 指针
  temp+`os.replace` 原子更新；重分析只追加，不删除旧快照。
- `_write_status` 终态钩子接线，失败不影响主链路。
