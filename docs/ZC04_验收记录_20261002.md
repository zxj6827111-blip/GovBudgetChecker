## 1. 修改摘要

### 精确证据与页码

- 重写 `src/utils/issue_bbox.py`：移除相似文字、表名、行列交叉搜索及 bbox 合成逻辑。现在只保留调用方提供、明确标记为 `exact_cell`/`exact_span` 且 `verified` 的坐标，并校验物理页及页面范围。
- 无来源精确坐标的问题仍保留表、章节、行、字段和可验证页码，定位等级写 `region`；没有区域证据时写 `unresolved`。不再由表名或规则编号猜页码，不将说明文字变成原文 evidence。
- 逐条独立核验表间引用：各引用保留自己的页码与 bbox，不把主引用坐标复制到另一侧。两页 PDF 引用越界页时，越界页及其 bbox 被移除。
- AI 摘要的页码只从有效显式页码或能映射回原页的 span 得出；缺页码时保持空。
- `IssueItem`、规则 `Issue`、引擎转换、分析结果和 CSV 增加定位等级与验证状态字段。

### 统一 ReviewReport 与导出

- 新增 `src/schemas/review_report.py`，由生产流水线终态 payload 构建 `schema_version=2` 的 `ReviewReport`，包括材料画像、结论、确认问题、提示、待复核、检查回执、义务覆盖及人工决定字段。
- 状态结果、前端问题列表和报告下载优先读取同一 ReviewReport；问题与提示分别存放，兼容导出时合并去重。
- JSON 提供完整 ReviewReport；CSV 新增 `record_type` 摘要、问题、提示、待复核和检查记录；Word 展示结论、待复核和回执；PDF 在原件副本上对已验证精确框作标注，并追加分页完整清单附录。零问题报告也输出附录；原件不修改。
- CSV 与导出定位保留 `location_level`、`verification_status`；未验证坐标不被展示或用于 PDF 标注。
- Review Workbench 支持跨表引用分别跳到各自页；仅对验证通过的精确框高亮，区域引用仅导航到页。

### 反例调整

- 将 bbox 测试从“搜索相似行/表名后应生成 bbox”改为“不推断 bbox”；新增精确来源坐标保留、源证据框提升及越界坐标拒绝测试。
- 原先对表名 fallback 的严格 xfail 现作为通过态反例执行。
- 零问题且检查完整的 PDF 也按导出约定附加结论页；相应更新 ZC-00 中以“完整时不生成附录”为预期的旧测试。

## 2. 必须验证对照

| 验证项 | 结果 |
|---|---|
| 只找到表名或行文本、无来源 bbox | 不生成 bbox；保留区域/未定位字段 |
| 只有 AI quote 或相似原文 | 不推断 bbox；保留实际引用文本 |
| 标记为 exact 且 verified 的来源 bbox 在 PDF 页内 | 保留 bbox |
| 一页 PDF 的 finding 指向第 2 页 | 清除无效页码和 bbox |
| 两个表间引用各自有坐标 | 坐标分开核验、分别导航，不复制主 bbox |
| ReviewReport 问题与遗留 projection 不同 | UI 和下载采用 ReviewReport 并去重 |
| 零问题但检查未完成 | PDF 附录说明未完成范围，不宣称材料无问题 |
| 已完成的零问题报告 | PDF 副本带完整结论附录；原件字节不变 |

## 4. 对接口、存储和历史兼容的影响

- 终态 job payload 增加 `review_report`；历史记录没有该对象时，JSON/CSV/Word 保留兼容读取，并明确标记旧版检查范围未记录。
- `IssueItem` 新增可选语义字段，旧 JSON 可按默认 `unresolved`/`unverified` 读取。
- PDF 下载生成的 `annotated.pdf` 是派生副本，包含注释及附录；源 PDF 不被修改。
- 物理页使用原件页序号。历史坐标只有存在 exact/verified 标记且页面校验通过时才可用；没有验证来源的旧 bbox 不作为精确框。

## 5. 尚未解决事项

1. **精确坐标来源尚未贯通解析器**：现有统一解析对象还没有将每个问题操作数关联到稳定 `EvidenceRef`/单元格 ID，并由解析器提供 exact bbox。因此真实规则结果多数只能区域导航；测试中的 verified 坐标是契约测试输入，不证明 PDF 解析定位准确率。
2. ReviewReport 目前是在生产终态 pipeline 中构建的兼容报告对象，未替代所有既有 `IssueItem`、`CheckReceipt` 和复核数据库模型；人工决定及历史 analysis revision 只在来源 payload 有数据时携带。下载端还没有显式的历史 revision 选择参数。
3. 跨表证据现可逐引用导航，但计算规则仍未全面保留左右操作数事实身份、公式及各侧证据 ID；这项依赖 ZC-03 的 FiscalFact 全量迁移。
4. PDF 导出附录和页面 UI 虽消费同一报告数据，但缺少真实 PDF 解析器向报告注入 verified cell/span 证据的端到端实测。
5. 无人工标准答案和真实扫描/混合 PDF 评测集，不能计算定位率、精确率、召回率；业务验收未通过。
