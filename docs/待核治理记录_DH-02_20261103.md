   三公说明与占比 / 说明科目绑定 / 分项范围 / 经济分类 / 完成率分母 / 投影层 9 处 raise。

   约定导出块（unfinished_check）→ docx 未完成清单 → 前端适配器类型`。

   “第N页表代码”直接作为阻断位置，说明缺表述类用章节标题定位页码。
