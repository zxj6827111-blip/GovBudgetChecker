## 1. 修复的 SYS 编号与修改摘要

### SYS-07 未知页码转第 1 页、问题说明充当原文、证据门只查非空

| 文件 | 修改 |
|---|---|
| `src/schemas/issues.py` | `IssueItem.page_number` 默认值 `1` → `None`（页码未知保持空，不再伪装第 1 页）；`AnalysisConfig` AI 相关默认值统一关闭 |
| `src/services/engine_rule_runner.py` | `_normalize_page` 无效页码返回 `None`（原折算为 1）；`_build_evidence_list` 只保留规则真实 `evidence_text`，删除 description/message 回退（问题说明不再充当原文）；规则执行失败记录不再伪造"第 1 页 + 错误消息即原文"的证据 |
| `src/services/ai_findings.py` | AI 问题缺页码时保持 `None`，不再默认第 1 页 |
| `src/engine/common_rules.py` | 收支总表类款规则定位不到总表页时保持缺页，不再填 1 |
| `src/utils/issue_display.py` | 展示层"原文摘录"不再回退到 `message` |
| `src/services/evidence_guard.py` | 证据门升级：① 真实页数边界核验（`document_page_count`，越界记 `page_out_of_range`）；② 原文引用核验（`page_texts` 逐页文本层，引用不存在记 `text_not_found_on_page`，扫描页/无文本层如实记 unverified）；③ 停止采信可由 message 派生的 `display.evidence_text`；④ 每条 finding 写入 `evidence_verification`（verified/unverified/failed + 原因），度量新增 `verified_count/unverified_count/failed_count` |
| `api/main.py` | 流水线调用证据门时传入真实页数与逐页文本 |
