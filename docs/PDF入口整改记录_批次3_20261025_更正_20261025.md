## 3. 五项缺陷的处置（本轮按 B 档：A + F2 + F1）

### F3 [P1] 逐格召回分母会排除漏读行/整表 — **已修**

位置：`scripts/score_cell_truth.py`（原第 154、168 行）。

原实现：找不到整表直接返回全零；找不到某行时在累计金额格之前 `continue`。
后果是分母取决于系统读到了哪些行——漏得越多，召回越高。

修复：
- 分母改为**先由真值独立固定**，再比对系统输出；漏表、漏行、漏列仍计入应检数量。
- `BLANK` 判定不再把“格不存在 / 列未映射”当作保持空白成功。
- 缓存键从“仅原件哈希”改为“原件哈希 + 解析器指纹”，避免改码后继续评分旧解析。
- 新增 `SCORER_VERSION = "cell-truth-v2"` 并写入 `score.json`。

证据：`scripts/score_cell_truth.py`；重算结果 `outputs/intake_remediation_20261024/ir18_cell_truth_v2_20261025/score.json`。

### F2 [P1] 人工确认表种不接受解析器真实的 UNKNOWN 编码 — **已修**

位置：`src/services/manual_cell_overlay.py`、`app/app/components/review-workbench/correctionAdapters.ts`。

原实现：解析器产出 `UNKNOWN_P1_T0`，前后端只把字面量 `UNKNOWN` 当未识别。
结果：界面不显示表种确认入口；即使直接提交也被“已识别表种 UNKNOWN_P1_T0 与提交表种不一致”拒绝。
**该功能在真实链路上从未可用。**

修复：新增共享判定 `is_unknown_table_code()`（Python）与 `isUnknownTableCode()`（TypeScript），
统一接受 `UNKNOWN` 与 `UNKNOWN_*` 前缀；已识别表种之间的冲突门保持不变。

证据：复核方脚本本体复验 `outputs/intake_remediation_20261024/fix_verification_20261025/reproductions.json`
（`unknown_table_confirmation.applied = 1`，非法行仍 `applied = 0`）。

### F1 [P1] 几何候选把合法的相同金额当作重复 — **已修**

位置：`src/services/pdf_parser.py`（`_structure_priority`，原第 2279 行）。

原实现：同一行内数值字符串去重差数 `len(amounts) - len(set(amounts))` 作为惩罚。
两个来源列印相同金额在财政表里很常见，于是“完整候选”反而比“缺一列候选”得分低。

修复：改为按**原页字符 token 身份 + 格框重合**判定重复抽取：
- 同一个 `(physical_page, start_char_index, end_char_index)` 被多个金额格认领 = 真重复；
- 同一行两个金额格的 bbox 完全重合 = 合并格被重复展开；
- 没有来源证明的格不参与判定——宁可少罚，也不把“数值相同”当重复。

证据：`outputs/intake_remediation_20261024/fix_verification_20261025/reproductions.json`
（`geometry_drops_legitimate_repeated_amount.selected = "full"`，原为 `lost`）。

### F4 [P1] 名称内部删字被当成笔误 — **已修（2026-10-25 追加）**

位置：`src/services/org_binding_decision.py`（`conflict()` 内，原第 190 行）。

原实现：封面完全命中时，目录/正文标题比候选少 1~2 字且该短名不在组织库，
就记为 `heading_missing_characters` 并**继续自动绑定**。组织库缺一个名字
不能证明它就是笔误——删字也可能指向尚未录入的另一个单位。

修复：保留“原件文字不一致”的证据记录，但**不再豁免冲突**，一律转人工确认。
改写后：`bound` → `needs_confirmation`，原因码 `evidence_conflict`，
`original_text_inconsistencies` 仍保留一条。

影响面实测（235 份真实材料，逐份以自身封面名构造组织库做前后对照）：
**决策变化 0 份**。原因是本批唯一符合该形状的样本
（`上海市人民政府发展研究中心` 目录漏写「市」）在名称比较层就按
“行政区前缀可省”判为等价，从未走到该分支。也就是说这条放宽在本批材料上
没有带来任何收益，撤销它也不改变任何既有绑定。

## 7. 空白页（清单 E-02）改为必报（2026-10-25 追加）

原实现三处静默：第 1 页无条件跳过；版面层读不到时整段检查静默通过；
“无文字但有矢量图形”的页既不算空白也不报。另 OCR 门控把非白像素低于 1%
的页直接当空白跳过，稀疏内容（实测一页仅含矢量数字时非白比例 0.16%）
会被丢弃且无任何提示。

修复：
- `src/engine/checklist_structure_rules.py` `CMM015_PageIntegrity`：
  正文空白页 `warn`（原行为保留）；封面空白 `info`；仅含矢量图形的页
  `info`（“疑似内容未被识别”）；版面层不可读且存在无文字页时抛
  `RuleNotApplicable`，记“未检查”而不是通过。
- `src/services/ocr_pipeline.py`：空白判定改为“非白像素为 0”，稀疏页照常送 OCR。
- `src/services/table_reading_assessment.py`：新增 `blank_page_count` 指标，
  空白页仍不计入文本覆盖率分母，但不再从质量指标里消失。
- 新增 `tests/remediation/test_blank_page_rules.py`（7 条）。

真实材料验证：`上海化学工业区公共事务中心2022年度决算` 报第 6、16 页，
`上海化学工业区管理委员会2022年度部门决算` 报第 20 页，规则状态 `fail`；
页质量 `blank_page_count=2`、`blank_pages=[6,16]`。
