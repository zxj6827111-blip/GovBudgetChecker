## 功能与使用

入口为“系统设置 → 模板管理”，采用用户确认的方案 A，按五步操作：

1. 模板与来源：按文种、材料类型、源年度筛选，查看维护时间、适用年度、原件和审计导出。
2. 上传、比较：支持实际验证的 DOC、DOCX、PDF、XLS；保留原件、转换器、错误和来源。相同文件新收一次，保留新来源记录，不自动复制规则。
3. 审核与发布：查看成对差异及与前版差异；对照原件渲染件审核编号、表格和条件；逐项映射规范、提示语、样式、可选内容及有限变体；预览验证和影响后发布或复用。WPS 未开放。
4. 年度适用：选择地区、必要覆盖层、目标报告年度及能力；区分当年正式下发、确认无变化、未收到新版沿用、历史参考。缺少绑定时不偷偷改选另一年。
5. 历史、回滚与影响：先预览，再填写恢复理由，生成新修订。按年度、绑定修订、算法及能力筛选影响，明确列出读取失败；旧快照不完整的分析仍列待核。明确选择材料后才提交重算。

材料复核页“材料信息”页签内显示“材料写法与金额范围”。两项分别选择、分别填写依据和证据位置；默认均不修改，可只确认写法。unknown 记录为独立修订，模板不能补成确定值。声明/正文反向证据单独展示，冲突选择须明确核对。归档冲突不自动更改归档。

普通审校账号只可读其有权材料的依据、确认相应维度；模板维护需要现有管理员权限。只读账号及越权账号不能写入。

### 发布、槽位与回滚语义

- 新包配置不可变，以规范 JSON 摘要标识；原件、提取文本、manifest 及 XLS 单元格映射均受固定回执约束。旁改文本及其自报哈希也无法绕过已发布回执。
- 年度/同比上年度/名称槽位和排版变化须逐组审核。年度替换仅匹配带“年”的位置；金额 `2024.00`、科目编码和《文献》固定年份不能借槽位放行。支持同段年度与名称复合变化。
- 无变化复用同一个包；配置语义、金额单位、科目、字段、结构和条件变化要求新版及对应验证。
- 不完整、混用或未核实同批来源的模板对不能启用能力。暂未收到新版与确认无变化分别留痕；跨年写法能力需要准确包哈希、算法、独立标注及兼容验证记录。
- 每个任务开始时用单条 SQL 冻结当前绑定及不可变内容；解析后按合格画像选择冻结记录。并发发布不会改变运行中的任务。最终摘要保存到 `result.meta.binding.scope_resolution`，完整结果及处理摘要分别保存。
- 写法处理摘要独立于金额物化身份。金额事实不读取模板写法结果；模板发布、回滚和人工写法决定都不会自动确认新问题。
- 年度绑定有修订号和事务锁；重复/陈旧提交报冲突。回滚只恢复该键已有审核修订及其能力，并重新检查原件完整性。
- 离线只读批准的 ZIP 快照，必须提供整包 SHA-256；不能离线维护或跳过能力审批。
