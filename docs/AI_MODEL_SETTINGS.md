# 大模型配置与独立检查进度

## 界面操作

1. 管理员打开“系统设置 → 大模型与系统参数”。也可直接访问 `/settings?section=settings`。
2. 点击“添加模型”，填写配置名称、接口类型、API 基础地址、模型 ID、API 密钥、单次请求超时和最大输出 Token 数。
3. 可点击“测试连接”确认模型能返回响应。此操作会发送一条简短的真实模型请求；完整审校的响应格式仍以实际任务为准。
4. 选择默认模型，打开“启用大模型检查”。需要上传自动勾选时，打开“上传时默认启用大模型检查”，然后保存。
5. 在上传中心或批量上传窗口勾选“大模型检查”，选择本次模型，上传并开始分析。

支持 OpenAI 兼容接口，以及已有的智谱、豆包适配器。基础地址填写服务商的 API 根地址，不包含 `/chat/completions`。密钥保存后不会回显，修改其他字段时留空可保留已有密钥。

## 配置何时生效

保存模型配置无需重启。API 和 Worker 读取同一配置文件；任务提交时会保存加密的配置快照。修改默认模型、API 地址或密钥只影响之后提交的任务，正在解析、排队或检查的任务继续使用提交时的配置。重新分析会使用当前配置。

首次安装本功能需要更新依赖并重启 API 和 Worker，以加载新接口。前端需要使用更新后的构建。

默认保存到仓库 `data/ai-model-settings.json`，API 密钥使用 Fernet 加密。同目录的 `ai-model-settings.key` 由程序首次保存时生成，权限为 `0600`，应随配置一起备份。可用 `AI_MODEL_SETTINGS_PATH` 指定共享路径，或用 `AI_CONFIG_ENCRYPTION_KEY` 提供固定 Fernet 密钥。多个 API/Worker 实例必须共享配置、加密密钥和上传目录；Docker Compose 已挂载共享数据目录。

未保存界面配置时兼容既有环境变量。首次保存之后以界面配置为准，包括关闭开关。配置管理和连接测试仅允许管理员操作；普通用户只能读取可用模型名称和上传默认开关。

## 进度含义

- **本地检查**：已执行规则数 / 实际选中的规则总数。规则异常显示“部分完成”，保留失败计数。
- **大模型检查**：已处理文本段数 / 本次文本段总数。显示实际模型、排队、检查中、已完成、部分完成、失败或未启用。
- 模型请求返回、失败或超时后才增加已处理段数；百分比表示已处理的检查单元，不是模型内部 Token 生成百分比。失败状态不会作为检查成功展示。
- 尚未解析完文档或无法度量总数时只展示状态，不估计百分比。旧的本地分析路径没有逐条进度时展示当前步骤和完成状态。
- 大模型开启时，上传完成后留在当前界面持续刷新进度，也可进入处理队列。队列、任务详情、重分析窗口与审核工作台展示同一份独立进度数据。
- 全文分段上限、响应截断、错误 JSON、连接失败等会显示失败或部分完成，已有本地结果继续保留，并沿用现有人工复核门禁。

## 后端接口

| 接口 | 权限 | 用途 |
| --- | --- | --- |
| `GET /api/admin/ai-models` | 管理员 | 读取脱敏模型配置 |
| `PUT /api/admin/ai-models` | 管理员 | 按 revision 保存配置，冲突返回 409 |
| `POST /api/admin/ai-models/test` | 管理员 | 测试指定模型，允许测试尚未保存的配置 |
| `GET /api/ai/capabilities` | 登录用户 | 查询可用模型和默认上传开关 |

分析启动接口新增可选 `ai_profile_id`；显式 `use_ai_assist=false` 可关闭本次大模型检查，未传开关的 dual 任务读取已保存的上传默认值。状态接口及任务列表通过 `check_progress.local`、`check_progress.ai` 返回两条独立进度。模型配置快照不会以明文进入任务状态、结果、前端响应或管理操作审计日志。

普通健康探针仅确认界面配置可以加载，不发送付费模型请求。实际连接是否可用以“测试连接”和审校任务结果为准。模型超时按每个请求生效；批量检查的时间预算计入分段数量和重试，仍受现有整个管线的硬时限约束。
