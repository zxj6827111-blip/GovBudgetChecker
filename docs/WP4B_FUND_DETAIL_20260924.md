### 为什么两者属于同一口径（可比性论证，逐项确认）

3. **资金性质**：双方均为「政府性基金预算财政拨款」——表名与说明章节标题逐字对应。
4. **业务项**：说明写全三级「住房保障支出（类）超长期特别国债安排的支出（款）其他住房保障支出（项）」，
   与表内 221/22198/2219899 三级科目的名称逐级完全一致；2219899 是本表唯一项级科目，映射无歧义。
5. **指标（measure）**：说明金额紧跟「（项）」出现在「支出具体情况如下：」引导的支出明细句里，
   同段并写明「年初预算为 0.00 万元，支出决算为 135.00 万元」——绑定的是**本年支出决算数**，
   不是预算数、不是上年数、不是收入（105.00）、也不是说明开头两句的收支总额。
6. **单位**：两侧均为万元。

## 三、实现口径（fail-closed）

- 比较对象：**说明中以「X（类）Y（款）Z（项）<金额><单位>」句式明确列示的项**，
  逐个在表内按「编码层级 + 三级名称逐级全匹配」定位同一业务项后比金额。
  - 禁止按金额就近配对；禁止只凭项级名称 fuzzy 匹配（类/款名称不同 = 不同业务项）。
  - 说明项在表中定位不到 / 命中多行 / 层级不全 → 记取数不足，不出正式 finding。
- measure 绑定：项金额必须是「支出具体情况如下（含变体）」之后的支出明细句；句前缀出现与材料年度
  不同的显式年份 → 不绑定（不跨年度比较）。说明金额必须自带单位字样。
- 金额：全程 Decimal；单位归一到万元（元=0.0001、亿元=10000，AGENTS.md 口径）；
  舍入包络用 `compute_dynamic_envelope`（表侧显示精度×表侧单位 + 说明侧显示精度×说明侧单位）；
  包络内降 info（"可能为取整误差"），超包络才是 error 正式 finding。
- 每个 fund scope（FIN_08 / FIN_09）**独立判适用性**：
  - 表缺失且说明无逐项表述 → 该 scope 无比较对象（表在位性归九表规则）；
  - 表空（无可读非零金额）+ 说明称"无…收入和支出" → 该 scope 一致（真实负例：生态环境局 P18/P19/P27）；
  - 表空 + 说明列示了项 → 取数不足；
  - 表有数据 + 说明称"无…" → 正式矛盾 finding；
  - 表有数据 + 说明章节缺失 / 无可绑定逐项表述 → 取数不足。
  - 两个 scope 任一取数不足都不得拖垮另一 scope（部分冲突经 partial_issues 保留）。
- 证据契约：finding 同时带表格侧（表名/页/行/编码/列）与说明侧（章节标题/页/命中原文），
  location 含 table_amount / narrative_amount / difference / unit / fiscal_year / fund_scope / obligation_id。
