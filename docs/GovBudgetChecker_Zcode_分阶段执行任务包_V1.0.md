## 二、全阶段统一技术契约

以下契约在 ZC-01 固定，后续阶段直接使用，不各自再建一套模型。

### 1. 数据模型

| 对象 | 必需内容 |
|---|---|
| `ParseArtifact` | 文档哈希、解析及配置指纹、全部物理页、逐页状态、文字块、表片段、逻辑表实例、单元格、坐标变换 |
| `FiscalFact` | 主体、合并范围、财政年度、期间、资金范围、预算阶段、指标、科目或项目身份、原始值、单位、显示精度、归一值、证据引用、识别状态 |
| `EvidenceRef` | 文件哈希、物理页、印刷页码、来源块或单元格 ID、原文、bbox、来源方式、验证状态、定位等级 |
| `CheckReceipt` | 规则 ID、子检查 ID、所需事实、实际操作数、公式、容差、状态、未完成原因、问题引用 |
| `ReviewReport` | 材料画像、适用范围、版本、确认问题、提示、待复核、全部检查回执、人工决定及证据 |

复用并扩展现有 `ParsedCell/ParsedRow/ParsedTable`，集中定义后保留原导入路径的兼容导出。数据库解析对象通过适配器转换，避免形成第三套独立解析语义。

### 2. 身份、数值与状态

- `table_code` 是表种，不是实例 ID。同种表可以存在多个独立实例。
- 事实 ID 必须区分主体、年度、范围、指标和来源位置；不同来源的候选事实不能因金额相同而覆盖。
- 问题 ID 根据检查关系及事实、证据生成，不能只根据“规则号＋页码＋标题”生成。
- 原始金额和归一金额分别保存。JSON 使用十进制字符串；旧浮点字段只作显示兼容，不参与计算。
- 空白、零、破折号、无此项和未识别分别处理。只有明确的表注或模板约定允许将特定符号解释为零。
- 问题的**严重度**与**是否确认**分开保存。待复核项保留候选严重度，但不计正式问题。
- 模型识别分数保留为识别分数；没有业务校准依据时，不生成貌似精确的问题正确概率。

子检查沿用六态：

`pass / fail / not_applicable / insufficient_data / parse_error / execution_error`

存在未完成子项时，整条规则不得记完整通过；已经确认的其他问题仍需保留。

### 3. 容差判定

设金额差额为 `Δ`，依据操作数原始单位和显示精度计算舍入包络 `E`：

- `Δ=0`：通过。
- 非零差额处于舍入包络内：提示“可能为取整误差”。
- 超出舍入包络但不超过 0.5 万元：按当前政策容差通过，回执保留差额。
- `Δ > max(0.5万元, E)`：在事实可比、来源可靠的条件下判不一致。

比例采用同样原则，政策阈值为 0.1 个百分点。

零分母、单位数量级、年度及科目用途错误使用各自规则，不套用金额容差进行豁免。

### 4. 坐标与证据

- 物理页从 1 开始，印刷页码独立保存。
- bbox 使用统一 PDF 页面坐标，保存渲染、旋转和裁剪变换。
- 定位等级固定为：`exact_cell / exact_span / region / unresolved`。
- 未知页码、位置保持 `null`，不得默认第一页。
- 问题说明与原文引用分开；引用必须关联来源对象。
- 引用归一化可以处理全半角及空格，但不能改变数字、小数点、负号、单位或百分号。
- 文档级缺表、缺章节使用完整检查范围作为证据，不伪造某一页的缺失原文。

### 5. 公共接口

保留现有上传、状态、复核及下载入口，新增：

**证据读取**

`GET /api/jobs/{job_id}/evidence/{evidence_id}`

返回原文、来源位置、定位等级、验证状态及证据图；支持指定历史 `analysis_revision`。

**人工校正**

`POST /api/jobs/{job_id}/corrections`

提交内容包含：

```json
{
  "analysis_basis_token": "当前分析版本标识",
  "changes": [
    {
      "target_type": "fact",
      "target_id": "事实ID",
      "field": "raw_value",
      "value": "35.20",
      "evidence_ids": ["原始证据ID"]
    }
  ],
  "reason": "人工复核理由"
}
```

可修改字段限定为原值、单位、年度、主体、合并范围、指标、列映射及人工定位。归一金额由系统重新计算，不能直接任意覆盖。

旧版本提交返回 `409`；无权访问沿用现有鉴权。成功后返回新分析版本和受影响检查范围。

**报告**

新结果增加 `schema_version=2`、`analysis_revision`、`checks` 和证据引用。原有结果字段由兼容适配器生成，不独立计算。

任务处理状态与审校结论分别表达：处理完成不等于检查完整。

7. 增加误报归因和漏报补录，保存规则、解析版本及事实上下文。

**反馈原因固定为**

解析错误、口径绑定错误、规则适用错误、容差错误、重复问题、证据或定位错误。

反馈经业务确认后才可进入标准答案或规则修订。点击忽略不能自动改变规则，也不能把未完成检查改成通过。

**必须验证**

旧版本提交、并发修改、单位校正、列映射校正、受影响关系重跑、无关回执复用、旧决定失效及原始记录保留。

### ZC-06：修复合并机制，预留 AI 接口

**对应缺陷：SYS-06。**

**修改内容**

1. 模型输入只使用明确的事实和证据；输出只允许候选事实、证据引用、语义疑点及不确定点。
2. 数字计算、单位换算、分母和规则严重度由确定性代码负责。
3. 合并以事实及检查关系为键，禁止仅凭标题相似、页码相近或金额接近合并。
4. 保留全部来源和原始结论，不再强制选择 AI 的问题 ID。
5. 修复冲突键及枚举不一致；冲突不能同时记为一致。
6. 单项异常保留原结果和异常回执，不清空整批 AI 或规则结果。
7. 有完整确定性证据的规则结论不被较弱 AI 意见覆盖；确实无法裁决的事实冲突进入复核。
8. 首版仅使用模拟模型完成契约测试，不配置真实供应商、不发出真实调用。

**必须验证**

弱 AI 对强规则、金额冲突、严重度冲突、错误证据 ID、单项格式错误、模型超时及完全关闭 AI。

关闭可选 AI 不得导致全部规则材料自动显示检查未完成；必需业务判断尚无法完成时仍如实记待复核。

### ZC-07：真实业务评测、真实端到端及发布验收

**对应缺陷：SYS-09，并验收全部整改。**

**修改内容**

1. 从 ZC-00 起建立标准答案工具和标注规范，本阶段完成冻结及独立评测。
2. 改造回放工具，使其能够执行真实生产审校链。夹具回放与原始 PDF 回放分别统计。
3. 模拟接口的 UI 测试继续保留，同时新增真实 API、Worker、PostgreSQL和 OCR 的上传到导出测试。
4. 使用独立测试项目、端口、数据卷和专用环境文件，不读取或写入业务上传目录。
5. 核实新链路真实消费全部适用规则后，才切换正式默认入口。
6. 更新 CI 的服务清单验证，规则模式不要求 AI 服务，不能继续固定只认旧五组件组合。
7. 保留历史结果和版本，回滚切换代码入口，不删除新生成数据。

**真实端到端最少四条**

- 正常原生预算。
- 含真实或明确测试缺陷的原生决算。
- 扫描预算。
- 混合决算，包含人工校正和重新检查。

接口不能被模拟替代；必须看到真实任务被 Worker 消费、证据来自原件、校正改变相应结果及全部下载成功。

### 3. 标准答案与盲测纪律

起步不少于 64 份真实 PDF：开发集、独立盲测集各 32 份。

按“预算/决算 × 部门/单位 × 原生/扫描”八组分层，每组在两个集合中至少各四份。混合 PDF 另外标记，不能用同一文档的扫描变体跨集合凑数。

- 标注覆盖全文应检查事项、真实缺陷、正确负例、不适用及无法确认项。
- Zcode 可以生成标注草稿；最终业务真值必须有人工审核记录。
- 已参与修复的 14 份材料只作开发集。
- 现有六份盲测材料及 DOC-B1-007/008 在真值和用途冻结前，不运行新规则作为开发反馈。
- 原始 PDF 缺失则登记不可用，不能用缓存文本宣称已经验证解析。
- 盲测至少覆盖 100 个业务确认的真实缺陷组；不足时扩充真实材料。
- 人工注入问题单独统计，不计真实业务质量。
- 评测分母按人工认定的适用范围确定。系统误判类型、主体或解析失败，不得借此移出分母。
- 命中需要对应检查关系、事实身份及正确证据；共享一个金额、编码或短词不能自动算 TP。

### 4. 发布质量门槛

| 指标 | 要求 |
|---|---|
| 正式问题精确率 | ≥98% |
| 真实问题召回率 | ≥95%，待复核候选不算正式命中 |
| 核心及重大错误 | 固定验收集中不得漏报 |
| 精确定位率 | ≥98%；区域导航不算精确定位 |
| 证据真实性 | 正式引用全部可验证，页码无越界 |
| 确定性必查子项完成率 | ≥95%；数据不足、解析失败计未完成 |
| 回执覆盖 | 每个应检查子项都有状态及原因 |
| 导出一致性 | 页面与全部导出结论、问题、未完成范围一致 |
| 可重复性 | 同原件、配置及版本得到相同规则结果 |

分别报告预算、决算、部门、单位、原生和扫描结果；同时公布待复核率、重复报警率、样本量和统计区间。

没有标准答案、没有预测正例或没有真实正例时，相应指标标为不可计算，不能填 100%。
