## 五、怎么使用

- 环境：daily-main 工作区（`artifacts/daily-main`，main `ef72faa0`）；依赖容器 fiscal_postgres（5432）/ fiscal_ocr（9010）运行中。
- 启动：`npm run dev`（或单点 `npm run dev:backend` / `npm run dev:frontend`）。
- 流程：上传中心上传决算 PDF → 任务自动分析 → 审核台逐条复核（AI 参考条目经"查看大模型参考条目"直达）→ 确认签认（证据未回原件或 AI 必需未执行会被门禁阻塞）→ 导出（按当前复核会话导出签认决定，历史版本隔离）。
- 单表勾稽对账（可选）：`.venv/bin/python scripts/d1_table_reconciliation.py <pdf> --auto`。
