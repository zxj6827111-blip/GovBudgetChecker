## 1. 修改清单

### 表绑定、续页及三公列映射

- `src/engine/budget_rules.py` 删除“目标页最大表”选取及只检查下一页最大表的做法，按目标表签名评分；多表无充分身份依据时不猜表。
- 续页按表头、列数和标题冲突等证据逐页恢复；遇到新表身份冲突时停止拼接。预算样张第三页合计行由回归测试确认可恢复。
- `src/engine/common_rules.py` 的三公数值按表头语义匹配，不再按数字出现顺序固定映射；表结构不足时不拿说明文字假装表格证据。
- `src/services/document_profile_resolver.py` 修复连写“财政局 + 部门决算”标题被识别成政府级材料；增加普陀、虹口、浦东地区替换不变性测试。

### 统一解析对象及 OCR 候选

- `src/schemas/parse_artifact.py` 增加原生/OCR 文字块、逐页 OCR 状态、OCR 表格候选及坐标变换字段；未核实的 OCR 表候选与正式逻辑表分开保存。
- `src/services/pdf_parser.py` 按原生文字块写入解析对象并登记页旋转信息；解析器指纹更新为 `pdfplumber-cells-v3-zc02`。
- `src/services/ocr_client.py` 修正 multipart 图片上传契约，保留识别分数和页坐标；固定单页超时 120 秒、单并发。
- `ocr_service/app.py` 使用 PP-StructureV3，输出 OCR 文字和表格候选；启动时校验离线模型目录及 `MANIFEST.sha256`，提供模型指纹健康检查。无法验证变换的 bbox 留空，非线性矫正请求被拒绝。
- `src/services/ocr_pipeline.py` 默认关闭；启用后仅处理低文本页，渲染 DPI 为 300。原生/OCR 内容不覆盖，OCR 候选进入统一解析对象。
- OCR 暂不进入确定性规则输入：关键数字尚未做区域复识别和一致性验证，表身份及逐格置信度也未核实。相关页保持待复核，避免把识别候选当作正式财政事实。
- `src/db/migrations.py`、`src/services/parse_artifact_store.py` 增加统一保存和读取文字块、OCR 表候选及坐标变换；证据默认 `unverified`。
- `docker-compose.yml` 增加默认不启动、无外网路由的 OCR profile；`.env.example` 增加服务及模型清单指纹配置。
- `docs/GovBudgetChecker_Zcode_分阶段执行任务包_V1.0.md` 保存用户提供的完整任务包；保留现有 `.zcodeignore` 与可用性评估报告。

## 4. 对规则、接口、存储和历史兼容的影响

- 三公、目标表及跨页解析逻辑进入真实 `api.main._run_pipeline` 共用规则入口，不只修改结构化入库旁路。
- OCR 请求改为 multipart 上传，与 FastAPI `UploadFile` 契约匹配；容器端依赖新增 `python-multipart`。
- `ParseArtifact` JSON 增加文字块、OCR 表格候选及坐标变换；DB 新迁移 `2026-10-01_0023_parse_text_and_ocr_candidates` 为解析运行增加对应 JSONB 字段，不回填历史对象。
- OCR 输出的定位只在经验证的页面变换下生成 PDF 点坐标；旋转或变换不明时保留空 bbox。
- OCR 候选不参与确定性规则，扫描页质量门禁继续保持未完成，页面和导出不会把识别候选误报为已审校。
- 金额及比例容差未调整，规则未删除，标准答案未改写。
