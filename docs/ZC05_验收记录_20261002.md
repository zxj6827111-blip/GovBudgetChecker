## 1. 修改摘要

- 新增 `GET /api/jobs/{job_id}/evidence/{evidence_id}`：复用任务鉴权，支持当前或历史分析快照；可从报告显式证据引用读取，也可按任务关联的 `document_version_id` 查询解析证据表。返回原文、页码、bbox、定位等级、验证状态和源 PDF 预览地址。无法验证的页码或坐标会被降为未定位/失败，不用于精确框高亮。
- 新增 `POST /api/jobs/{job_id}/corrections`：检查当前分析 basis token；仅接受原始值、单位、年度、主体、范围、指标、表实例列映射及人工定位字段；要求校正原因为必填项，普通校正必须关联当前任务可读取的证据 ID。归一金额不能由请求任意覆盖。
- 校正写入任务目录的 `corrections.jsonl`，另含操作人、时间、理由、原分析版本、修改字段、原证据 ID 和记录 ID。写入使用 job 级文件锁、版本比较、追加写及 `fsync`；旧 basis 返回 409，并发追加保留全部记录。
- 人工定位页码和 bbox 按源 PDF 页数及页面尺寸校验，保存为 `source_method=manual`、`verification_status=unverified`、`location_level=region`；不会伪装成原生文字/OCR 的已验证精确证据，可由证据读取接口再次取回。
- 新增 `POST /api/jobs/{job_id}/feedback`，固定误报/漏报类型及六类原因码。反馈追加到 `feedback.jsonl`，标为等待业务确认；不会自动修改规则或标准答案。
- 返回受影响检查映射；只依据检查回执中的显式事实 ID，不按标题、页码或金额猜关系。无法建立事实依赖时返回 `status=unknown`。

## 2. 必须验证对照

| 验证项 | 结果 |
|---|---|
| 读取当前报告中的证据 ID | 返回原文及来源字段；有效精确坐标生成带 bbox 的预览地址 |
| 读取人工标记 | 保持人工来源和未验证状态；预览不生成精确 bbox 标记 |
| 提交旧 analysis basis token | 返回 409；不创建校正记录 |
| 同时追加两条记录 | 文件锁串行化写入；两条 JSONL 均保留 |
| 原值、单位及列映射校正 | 仅保存覆盖层；原 `status.json` 分析代际不变 |
| 直接提交 `normalized_value` | 请求字段白名单拒绝，返回 422 |
| 误报/漏报原因码超出固定集合 | 返回 422；合法原因进入待业务确认队列 |
| 回执包含被改事实 ID | 返回对应 `sub_check_id`；不声称已重跑 |
| 回执缺事实依赖 ID | 受影响范围明确为 unknown，不做猜测 |

## 4. 对接口、存储和历史兼容的影响

- 新接口已注册到 FastAPI。证据读取及校正写入均经过 `require_job_access`；任务路径拒绝目录穿越。
- 追加覆盖文件不会修改原 PDF、`status.json`、解析事实或分析发现。旧 JSON 状态照常可读。
- 当前 evidence DB 查询仅在环境配置数据库且状态中能解析到 `document_version_id` 时启用；数据库不可用会返回 503，而不是伪造空证据。
- feedback 原因码为 `parse_error`、`caliber_binding_error`、`rule_applicability_error`、`tolerance_error`、`duplicate_issue`、`evidence_location_error`。

## 5. 尚未解决事项

1. **没有执行局部重算**：ZC-03 记录的 82 条生产规则仍未全面消费 `FiscalFact`。当前校正只能留存审计覆盖层；响应明确返回 `new_analysis_revision=null` 及 `reanalysis_status=not_executed_fact_overlay_not_consumed_by_production_rules`。不能据此宣称校正已影响检查结果。
2. **复核决定尚未失效**：没有新分析版本发布，既有人工决定保持原样，接口显式返回 `review_decisions_status=unchanged_until_new_analysis_is_published`。待覆盖层接入事实规则并发布新版本后，再接入已有复核生命周期失效钩子。
3. 检查依赖只有在回执带有显式事实身份字段时才能映射；当前生产回执多数是 `legacy_document` 代理回执，所以常返回 unknown。
