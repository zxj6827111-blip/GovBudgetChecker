## 二、F5：原始 status 指纹（bbox/location/证据结构）

### 修复

新增只读原始 status 抽取与对照，**不再只依赖 `gm._row`**：

- `load_raw_index(run)`：按 `(文档, 类型, 身份)` 索引 `review_report.issues/tips`、`manual_review[].finding`、`check_coverage.instances`。
- `canonical_raw`：排除纯运行标识（`id/analysis_revision/created_at/model_version/prompt_version`），保留并比较：
  - 规则/子检查、标题、去展示序号的正文；
  - 严重度、`bbox`（顶层）、完整 `location`（含 `page/pos/section/table_code/指标身份/actual/expected/difference` 等）；
  - 完整 `evidence[]`（page/physical_page/bbox/quote/text/source_span/source_block_id/source_method/evidence_id/verification_status）；
  - `evidence_explanation`、`evidence_ids`、`fact_ids`、`obligation_ids`、`evidence_verification` 等。
- 浮点 bbox 统一保留 3 位小数，避免序列化噪声。
- 引用 ID 只在**已验证**时归一：
  - 条目 ID：由唯一对齐的 `新 raw_id → 旧 raw_id` 映射；
  - `pre_group_issue_id`：同文档同规则组内按顺序验证的 pre-group 映射；
  - `member_issue_ids` / `merged_issue_ids` 等合并成员：同结构同位置共现票，只有唯一票才采用；冲突记 `reference_vote_conflicts` 并使 `ok=false`。
  - 未验证/未映射引用保留原值参与比较，产生 `raw_fingerprint_drift`，不做整体豁免。
- 已批准附带变化单独记账，不影响其他字段：
  - `approved_ledger_detail_changes`：O 层义务账本 `detail` 规则 fail→pass，且无其他字段变化；
  - `approved_notice_count_changes`：N 层 `rules_insufficient_data` 的 `partial_findings_count`，且该计数所属规则确有目标移除（本次仅 GS-2025-01 V33-TREND-COMPLETION-RATE 1 条）。
