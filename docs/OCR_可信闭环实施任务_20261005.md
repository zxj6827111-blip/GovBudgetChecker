## 2026-10-05 历史断点

现有链路为 `ocr_service/app.py → pdf_parser.py → ocr_fact_promotion.py → fiscal_fact_materializer.py → FactContext → 规则/证据门`。

- 服务保存整体 OCR 文本块的分数、表 HTML 和表级框，没有把逐格识别分数、逐格框和合并关系交给解析器。
- 候选晋升固定使用 0.75，单元格复用表级框；事实仍为 low_confidence，自动操作数为 0。提高这个常数不能解决识别可信度。
- 模型清单核验已有实现，但构造器没有逐子模型显式绑定本地目录，ready 在真实预热推理前设置；需证明加载的是已核验文件且运行时不会下载。
- 现有坐标主要覆盖无旋转、无裁剪偏移的转换；扫描文本不能通过 ZC07 当前的原生 PDF 文本引文认证。
- `models/MANIFEST.sha256` 当前缺失，高质量扫描件、低质量扫描件及扫描校正后的真实服务证据尚未交付。

官方 PP-StructureV3 文档提供表格单元格框、表内 OCR 文本/分数以及本地模型配置接口，可作为适配起点。但官网主线不等于仓库锁定版本：实施首先从当前镜像的 PaddleOCR 3.7.0 / PaddlePaddle 3.2.0 采集实际返回契约，再决定映射，不能直接假定数组一一对应。[官方接口说明](https://www.paddleocr.ai/main/en/version3.x/pipeline_usage/PP-StructureV3.html)

## 协议字段与资格策略

以下是完整语义要求；当前逐格版本为 `gbc.ocr.cells.v2`，实际字段以代码和实跑响应为准。尚未满足的部分不能仅据此表视为已支持。

| 层级 | 必需内容 | 无法识别时 |
|---|---|---|
| 请求/响应 | schema_version、request_id、source_sha256、physical_page、model_manifest_sha256、pipeline_config_sha256、runtime/image 版本 | 返回失败原因，不沿用其他请求的模型或原件身份 |
| 渲染 | render_sha256、像素宽高、DPI、PDF 页面尺寸、坐标原点、旋转、裁剪偏移、变换矩阵/版本 | 保留候选，不生成可信 PDF 框 |
| 表/格 | table_id、row/column、rowspan/colspan、source_cell_id、raw_text、识别片段、每段 raw_score/render_polygon、cell_render_bbox/cell_pdf_bbox | 缺原始片段和框不得造分数；空格、无此项、0分别编码 |
| 单位/列/主体 | 单位证据、金额列身份、年份、主体全称和有来源简称、预算阶段、资金口径及其证据 ID | 不从金额大小猜单位，不借邻行/他单位/上年身份 |
| 资格/认证 | operand_qualification.status/reasons、使用的分数集合、区域复识别记录；独立 evidence verification 状态与方法 | 两种状态分开；缺认证保持 unverified |

初始开发策略建议使用所有关键数字和单位片段的最低真实识别分数 ≥0.98，并要求完整身份、唯一结构、有效格框、原件/模型指纹和局部重识别一致。**0.98 是待开发集校准的候选阈值，不是准确率承诺**；禁止用平均分遮盖一个低分小数点或单位。若锁定运行时没有单位/数字的细粒度分数，保留较粗片段的最低分并记录粒度，不能拆出伪造字符分数。

局部重识别要保存新裁剪输入和返回结果，不能复制第一次文本。相同模型复识别仍可能重复同一种错误，因此只能用于冲突检测；真实可靠性由独立冻结人工真值检验。阈值、可接受变换、列映射策略、超时和模型均在开发集调定并冻结后才盲测。

跨页合并保留原物理页和原格 ID；“事实属于续表”不能替换原件位置。同一原件、模型、配置应产生同一事实/证据身份，不把随机 job_id 或 parse_run_id 当作稳定身份。

## 最低测试材料与证据包

开发材料至少覆盖：清晰扫描正确算式与真实错误算式；模糊/压缩数字；0/O及小数点；万元/元/亿元；四方向页面与裁剪；合并表头/续表；预算与决算双列；他单位/往年引用；原生和 OCR 冲突；无文本混合页；人工校正后重审。每类有原件、真实裁剪和人工真值，允许同一份开发材料覆盖多个风险，但不得据此替代八层盲测配额。

每次实跑保存 `source.pdf`、原始响应 JSON、页渲染及格裁剪、模型清单/配置/镜像指纹、候选和拒绝记录、入库事实/证据引用、关系回执、trace、四格式及重复下载 SHA。包内所有证据通过一个哈希清单关联，未完成项写明确原因，业务指标不可计算时为 null。

性能记录真实输入页数、渲染耗时、首轮/复用推理耗时、内存及超时次数；用配置中的页/区域超时核验，不自行把超时任务算完成。开发样例通过后，也必须在同一冻结版本的独立扫描盲测上达到发布门槛。
