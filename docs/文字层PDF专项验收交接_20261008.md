## 必查反例

| 场景 | 应检查的行为 |
| --- | --- |
| 预算与决算同段、决算词跨行或跨页 | 不串阶段；仅删除有原页证据的终端物理页码干扰；引用仍保留原文 |
| 跨页表头重复、列位置变化、单独合计页 | 合并后逐行逐列核对，证据指回原物理页与原单元格 |
| 三公完成率及结构占比 | 同分项决算/同分项预算，或同分项决算/三公决算合计，分别绑定 |
| 空白、0、缺失或身份歧义 | 空白不补0；真实0保留；不确定关系显示未完成并保留其他已确认问题 |
| 0.01万元差、单位换算、经营等其他支出组成列 | 容差和取整提示正确，经营/上缴/附属单位等列不能漏计 |
| 一般公共预算及基金使用相似科目名称 | 分别按资金章节和同级科目比较，基金预算0不替代基金决算 |
| “基本持平”、只有结果的原因、编号跳号 | 不把定性程度推成严格数值矛盾；编号问题不推断缺科目 |
| 已知金额校正后重审 | 当前版本使用校正金额、实际缓存读回及本版入库完成；旧版本、原金额和原证据仍可回放 |
