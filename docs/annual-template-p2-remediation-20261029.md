空行、句末标点、无关文本、跨页、引用及否定语境仍中止或拒绝匹配。规范表名仍须唯一关联合格逻辑表与物理片段；错误标题、错误页、无实例、重复实例、未绑定 OCR 表仍转待核。没有改为全文子串搜索或取消来源绑定。

同时保留原始行长度累计，标题证据的 start/end 包含实际换行与缩进，不能用去空白后的标题长度当原件结束坐标。编号独占一行时允许重叠的标题候选，表实例唯一性要求保持不变。

新分析使用 `material-writing-v3.4`，新配置 schema 仍为 2。既有运行代码指纹继续记录具体源码；历史包、绑定、分析及其算法记录不改写。算法绑定的跨年度兼容证明须按当前版本重新核实，不自动挪用旧版本结论。
