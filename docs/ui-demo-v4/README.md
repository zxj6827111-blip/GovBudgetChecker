# GovBudgetChecker v4 DEMO

本轮根据 KIROGOVCOMPARE 的页面逻辑重新组织，不再把地区配置放在日常首页。

## 设计结论

- 地区配置只做一次，放在系统管理/基础档案中；日常页面只展示当前工作区。
- 日常首页改为 `年度审校工作台`，同一个板块同时支持当前年度办理和往年数据追溯。
- 保留独立 `任务中心`，完整记录上传、检查、下载任务；任务抽屉只做快捷进度提醒。
- 新增独立 `问题数据看板`，按部门单位、问题类型、预算/决算、规则检查/AI 辅助检查汇总。
- 新增 `年度档案`，按检查年度查看往年预算、决算、历史问题、整改记录和导出包。
- 单份材料进入 `材料详情`，用页签组织材料内容、规则检查、AI 辅助检查、截图定位和整改记录。

## 页面

- `dashboard.html`：年度审校工作台，默认看当前检查年度，也可直接切换往年批次。
- `issues-dashboard.html`：所有问题数据看板。
- `archive.html`：往年数据/年度档案。
- `upload.html`：材料上传。
- `material-detail.html`：材料详情。
- `task-center.html`：任务中心与下载任务。

这是静态截图式 DEMO，不改正式业务页面，也不做统一门户首页。
