（MR-1 双栏取数、MR-2 舍入聚类、MR-4 口径门槛都不改规则码/严重度）。即该设计
对其唯一用途（换了 checker 要能归因）**完全失效**。已改为哈希引擎源码
（`rules_v33/budget_rules/common_rules/pipeline` 四文件字节），修复后三节点指纹
互不相同（`5adf97f8` / `c61c734a` / `7cd4c0d6`），同时保留清单哈希用于识别
「规则码/严重度漂移」，并与 `git_head` 并列。
