# GovBudgetChecker v3 流程式 DEMO

这一版按真实工作流程重新设计，不再以“工作台首页”为核心。

## 工作流

1. 地区配置：按省级、市级、区县、街道镇四级配置。上海示例为 `上海市 / 市辖区 / 普陀区 / 真如镇街道`。
2. 材料上传：选择检查年度后自动拆分材料年份，例如检查年度 `2026` 对应 `2026 年预算公开` 和 `2025 年决算公开`。
3. 错误查看：上传后查看错误，分为 `规则检查` 和 `AI 辅助检查` 两类，并展示截图、页码、定位和证据。
4. 错误下载：按地区、年份、材料类型、错误来源导出清单、截图定位 PDF、整改工作包。

## 页面

- `region.html`：地区配置。
- `upload.html`：年度材料上传。
- `issues.html`：错误查看。
- `downloads.html`：错误下载。

此目录仍是静态截图式 DEMO，不改正式业务页面，也不做统一门户首页。
